# Preview روی VM مستقل آروان‌کلاد — برنامه و نقاط تأیید

وضعیت: **آماده اجرا، منتظر تأیید مالک.** هنوز هیچ سرور پولی ساخته نشده و هیچ DNS تغییری نکرده است. این سرور فقط برای Manage است و هیچ منبع، کلید یا سرور Source by HEDAX در آن استفاده نمی‌شود.

## ۱. منابع پیشنهادی

| مورد | پیشنهاد | دلیل |
| --- | --- | --- |
| پردازنده / حافظه | ۲ هسته، ۴ گیگابایت RAM | اجرای دائمی کمتر از ۱ گیگابایت مصرف دارد؛ ساخت image وب (Next.js) در لحظه اوج تا حدود ۳ گیگابایت لازم دارد (۲ گیگابایت swap هم ساخته می‌شود) |
| دیسک | ۴۰ تا ۵۰ گیگابایت SSD | imageهای Docker، پایگاه داده آزمایشی، لاگ با سقف |
| سیستم‌عامل | Ubuntu 24.04 LTS | Docker و Compose از مخزن رسمی Ubuntu نصب می‌شوند |
| منطقه | دیتاسنتر تهران | کاربران در ایران‌اند و دسترسی در زمان اختلال اینترنت بین‌الملل پایدارتر است. برای Docker از mirror آروان استفاده می‌شود |
| شبکه | یک IPv4 عمومی؛ فقط پورت‌های 22، 80 و 443 | فایروال سرور (ufw) و در صورت تمایل فایروال ابری آروان |
| پشتیبان | لازم نیست | داده کاملاً ساختگی است و با اسکریپت از نو ساخته می‌شود |

گزینه ارزان‌تر: ۲ هسته و ۲ گیگابایت RAM، به شرطی که imageها در GitHub Actions ساخته و به سرور منتقل شوند. این حالت آماده نشده است؛ اگر هزینه مهم‌تر باشد اضافه می‌شود.

## ۲. هزینه تقریبی

سایت آروان برای خواندن خودکار قیمت محافظت شده است و قیمت رسمی به‌روز را نتوانستم مستقیم بخوانم. ارقام زیر **تخمین** هستند و قیمت قطعی هنگام ساخت سرور در پنل آروان نمایش داده می‌شود:

- منابع عمومی و قدیمی‌تر: پلن ۲ هسته / ۲ گیگ حدود ۱۶ یورو در ماه؛ پلن ۲ هسته / ۴ گیگ حدود ۱٫۹ میلیون تومان در ماه (تاریخ نامشخص).
- با توجه به تغییر قیمت‌ها در ۱۴۰۵، انتظار من برای ۲ هسته / ۴ گیگ / ۵۰ گیگ: **حدود ۲ تا ۵ میلیون تومان در ماه**.
- صورت‌حساب آروان ساعتی است؛ بعد از پایان دوره آزمایش، با حذف سرور هزینه متوقف می‌شود.

## ۳. دامنه و HTTPS

| گزینه | تغییر DNS | توضیح |
| --- | --- | --- |
| الف. زیردامنه از دامنه شما (مثلاً `preview.<دامنه>`) | یک رکورد A — **نیازمند تأیید شما** | پایدارترین حالت؛ با تصمیم Issue #6 هماهنگ است |
| ب. نام خودکار از روی IP (مثل `185-1-2-3.sslip.io`) | ندارد | برای شروع سریع؛ گواهی Let's Encrypt می‌گیرد ولی به سرویس عمومی sslip.io وابسته است |

پیشنهاد: برای شروع گزینه ب، و پس از انتخاب دامنه، گزینه الف.

## ۴. دسترسی امن

- HTTPS خودکار (Caddy و Let's Encrypt).
- **دروازه رمز برای کل سایت** (نام کاربری `preview` و رمز تصادفی) قبل از ورود به خود Manage. رمز فقط یک بار هنگام نصب نمایش داده می‌شود و روی سرور به‌صورت hash نگه داشته می‌شود.
- ورود Manage با نقش‌ها و قفل حساب، کوکی Secure، محدودیت تلاش ورود بر اساس IP واقعی.
- وب، API و PostgreSQL منتشر نمی‌شوند؛ فقط Caddy روی 80/443 است.
- SSH فقط با کلید (کلید جدید مخصوص Manage: `manage_preview_ed25519`)، ورود با رمز خاموش، به‌روزرسانی امنیتی خودکار، fail2ban.
- `noindex` برای موتورهای جست‌وجو.

## ۵. مراحل و نقاط تأیید

1. **[تأیید مالک]** ساخت سرور با مشخصات بالا در پنل آروان، در یک پروژه جدا با نام Manage. ساده‌ترین راه: خودتان در پنل بسازید و هنگام ساخت، این کلید عمومی را اضافه کنید:
   `ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAINslnpcAjHPDsLaWXjyYrjdxBAUTKcaZlvzc39AFCSsz manage-preview-deploy (HEDAX Manage, synthetic data only)`
   سپس IP سرور را بدهید. به کلید API حساب آروان نیازی نیست.
2. **[تأیید مالک]** انتخاب نام: sslip.io (بدون DNS) یا زیردامنه (یک رکورد A).
3. ورود با SSH و اجرای `deploy/preview/setup-server.sh` (فایروال، SSH، Docker، رمزها).
4. اجرای `deploy/preview/deploy.sh` و بررسی سلامت. لینک، رمز دروازه، رمز حساب‌های نمونه و سناریوهای آزمایش در یک پیام خصوصی به شما داده می‌شود (نه در GitHub).
5. ثبت لینک در PROGRESS.md و Issue #5.

## ۶. ریسک‌ها

- دسترسی Docker Hub از ایران محدود است: mirror آروان (`docker.arvancloud.ir`) تنظیم می‌شود. اگر بسته‌های npm کند یا در دسترس نباشند، با متغیر `NPM_REGISTRY` یک mirror تعیین می‌شود.
- دسترسی سرور به GitHub برای دریافت کد لازم است (مخزن عمومی است؛ کلید یا توکن GitHub روی سرور قرار نمی‌گیرد).
- این سرور Production نیست و داده واقعی وارد آن نمی‌شود.
