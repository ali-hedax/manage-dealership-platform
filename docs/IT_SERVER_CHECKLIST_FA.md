# چک‌لیست سرور داخلی نمایندگی — برای مسئول IT

هدف: تصمیم‌گیری درباره نصب Manage روی سرور داخلی تا در زمان قطع اینترنت هم کار کند. **تا پاسخ این پرسش‌ها، هیچ نصبی روی سرور انجام نمی‌شود.** پاسخ‌ها را در یک Issue یا پیام برای مالک پروژه بفرستید؛ رمز عبور یا اطلاعات محرمانه را در GitHub ننویسید.

## سخت‌افزار و سیستم‌عامل

1. سیستم‌عامل و نسخه دقیق (Windows Server نسخه؟ / Linux توزیع و نسخه؟)
2. فیزیکی یا مجازی؟ اگر مجازی، روی چه بستری (Hyper-V، VMware، …)؟
3. CPU (تعداد هسته)، RAM کل و آزاد، فضای دیسک آزاد و نوع دیسک (SSD/HDD)
4. چه سرویس‌هایی اکنون روی این سرور اجرا می‌شوند (حسابداری، انبار، فایل‌سرور، …)؟ مصرف فعلی منابع چقدر است؟
5. آیا امکان ساخت یک ماشین مجازی جدا برای Manage وجود دارد؟ (پیشنهاد حداقل: ۲ هسته، ۴ گیگابایت RAM، ۴۰ گیگابایت SSD، Ubuntu Server 24.04)

## نرم‌افزار و دسترسی

6. آیا نصب Docker (یا Docker Desktop روی ویندوز) مجاز است؟
7. دسترسی مدیریتی برای نصب و به‌روزرسانی با چه کسی است و از چه راهی (حضوری، Remote Desktop، SSH)؟
8. سیاست آنتی‌ویروس/EDR که ممکن است Docker یا Node.js را مسدود کند؟

## شبکه

9. محدوده IP شبکه داخلی و آیا می‌توان برای سرور IP ثابت تعیین کرد؟
10. کاربران از چه دستگاه‌هایی وصل می‌شوند (کامپیوتر، تبلت، موبایل روی Wi-Fi)؟
11. آیا DNS داخلی دارید تا نامی مثل `manage.local` به سرور اشاره کند؟
12. اینترنت سرور: سرعت، پایداری، و آیا اتصال خروجی HTTPS به سرور ابری مجاز است؟
13. فایروال: پورت‌های مجاز داخلی؛ آیا نیاز به باز کردن پورت ورودی از اینترنت هست؟ (طرح پیشنهادی: **فقط اتصال خروجی** از سرور داخلی به ابر؛ بدون پورت ورودی)

## برق، پشتیبان و نگهداری

14. UPS دارد؟ چند دقیقه؟
15. روال فعلی پشتیبان‌گیری چیست و نسخه پشتیبان کجا نگهداری می‌شود؟ امکان پشتیبان خارج از نمایندگی هست؟
16. چه کسی در صورت خرابی سرور پاسخگو است و زمان معمول رفع مشکل چقدر است؟

## امنیت

17. آیا گواهی HTTPS داخلی (CA سازمانی) دارید؟
18. محدودیتی برای ذخیره اطلاعات مشتری (نام، تلفن، پلاک، VIN، تصاویر) روی سرور داخلی یا ابری وجود دارد؟

## اگر نصب روی سرور موجود ممکن نباشد

گزینه‌های جایگزین با هزینه و محدودیت در گزارش بعدی مقایسه می‌شوند: (الف) یک Mini-PC اختصاصی با SSD و UPS در شبکه نمایندگی، (ب) فقط سرویس ابری بدون حالت آفلاین (ساده‌تر اما با قطع اینترنت کار متوقف می‌شود)، (ج) ماشین مجازی جدا روی سرور فعلی.
